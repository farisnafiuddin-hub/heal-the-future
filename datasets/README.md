# Dataset Heal The Future

Folder ini disiapkan untuk dataset AI Vision/OCR.

Struktur label contoh:

```json
{
  "image": "screenshots/strava_001.jpg",
  "distance_km": 4.71,
  "average_pace_min_km": "9:00",
  "moving_time": "42:26",
  "elevation_gain_m": 0,
  "max_elevation_m": 766,
  "calories": null,
  "quality": "clear",
  "layout": "strava_light"
}
```

Rekomendasi:
- minimal 200 screenshot untuk eksperimen awal
- ideal 1000+ screenshot untuk model serius
- variasikan Android/iPhone, light/dark mode, crop, blur, ukuran, dan bahasa
- jangan upload data pribadi sensitif tanpa disamarkan
